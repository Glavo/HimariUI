# ADR-011: Exclude preview and incubator types from stable APIs

- **Status:** Accepted
- **Date:** 2026-08-14
- **Decision milestone:** ADR-BOOTSTRAP-001
- **Evidence:** PLANS.md Sections 1.4, 4 (ADR-011), and 26; Java 25 API-signature policy.
- **Supersedes:** None
- **Superseded by:** None

## Context

Preview and incubator APIs can change incompatibly and would force application builds to enable unstable platform features.

## Decision

Stable exported signatures use only stable Java 25 APIs. Preview and incubator APIs, including the Vector API, remain inside optional implementation artifacts and never appear in stable public contracts.

## Consequences

Optional accelerated modules may require explicit runtime flags and versions while the scalar path and public API remain stable. Structured concurrency and other preview types cannot leak through callbacks, records, or generic arguments.

## Evidence

Publishing and API-signature gates inspect exported module surfaces before stabilization.

## Replacement

None. An API that becomes stable may be adopted internally or publicly through normal API review.
