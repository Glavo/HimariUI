# ADR-015: Separate value reactivity from structural updates

- **Status:** Accepted
- **Date:** 2026-08-14
- **Decision milestone:** ADR-BOOTSTRAP-001
- **Evidence:** PLANS.md Sections 4 (ADR-015), 7, 22 (M1), and 26; reactive literature and framework references in REFERENCES.lock.
- **Supersedes:** None
- **Superseded by:** None

## Context

Value propagation and mounted-tree identity have different correctness and ergonomics requirements. Treating them as one universal recomposition mechanism would prematurely select a slot-table model without compiler assistance.

## Decision

Use a fine-grained producer/consumer graph for state, lazy derived values, phase dependencies, and owned effects. Writes push invalidation; derived values recompute when pulled and publish a new semantic version only when their equality policy observes a change. Conditional branches, keyed collections, mounted identity, and lifecycle remain a separate structural-update problem.

## Consequences

ADR-023 selects explicit grouped recomposition for structural updates after the required three-way comparison. This ADR continues to govern value propagation: selecting restartable structure does not turn property bindings, derived values, or phase callbacks into one universal recomposition mechanism.

## Evidence

`himari-state` now provides one `ReactiveGraph` per `StateDomain`, explicit `ReactiveOwner` lifetimes, synchronous dependency capture with `ReactiveReads.untracked`, and lazy `DerivedState` values with configurable equality policies. Atomic source publication performs iterative dirty propagation only; pull-time dependency-version polling stabilizes upstream derivations and skips downstream execution when semantic versions remain unchanged. Successful executions reconcile dynamic edges, failed computations and equality policies retain the previous cache/version/edges and retry on the next pull, transactions use non-publishing ephemeral derivation, derived execution rejects state and ownership writes, and owner disposal detaches producer edges. Fixed fixtures cover lazy push/pull, equal-value suppression, diamonds, dynamic branches, untracked and later reads, deterministic cycles, cross-domain rejection, transaction rollback, failure recovery, and cross-owner disposal. A deterministic 2,000-transaction differential test compares dynamic values and semantic versions with a naive evaluator.

`RUNTIME-SAMPLE-001` now consumes this common value foundation through a structural-model-neutral adapter. Its frozen catalog, source metrics, execution probe, cleanup gates, and report schema are shared evidence only; the module contains no group, slot, anchor, scope, or reconciliation abstraction. `REACTIVE-001` therefore supplies the value graph while the grouped, one-shot, and hybrid work packages remain independent structural implementations.

`RUNTIME-SPIKE-GROUPED-001` keeps that boundary intact. Its diamond application uses the shared `DerivedState` graph, and its phase bindings compare `StateSource` semantic versions, while the candidate alone owns explicit group records, positional memory, keyed reconciliation, retained branches, effects, and atomic structural drafts. ADR-023 selects those structural semantics without replacing the shared value graph.

`RUNTIME-SPIKE-ONESHOT-001` keeps the same boundary through a different structural representation. Stable bindings poll shared `StateSource` semantic versions and write node properties without rerunning owner initializers; candidate-owned anchors alone reconcile `Show` and `ForEach` topology. Retained branches deactivate their value edges and effects, disposed branches release them, and every session balances graph edges after close. It remains comparison and optimization evidence rather than the selected public structural model.

`RUNTIME-SPIKE-HYBRID-001` keeps stable property bindings outside structural execution but permits the smallest explicit `structure(...)` callback to rerun when its topology source advances. Those callbacks use ordinary Java control flow to declare semantic-keyed fragments with retain or dispose policy; unchanged owners and bindings never rerun. All fixtures balance value edges and retained records after close. It remains comparison and optimization evidence rather than the selected public structural model.

## Replacement

None. ADR-023 completes the deliberately open structural subdecision without superseding fine-grained value reactivity.
