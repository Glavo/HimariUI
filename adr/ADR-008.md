# ADR-008: Prefer verifiable correctness over porting speed

- **Status:** Accepted
- **Date:** 2026-08-14
- **Decision milestone:** ADR-BOOTSTRAP-001
- **Evidence:** PLANS.md Sections 4 (ADR-008), 19, 22, and 26; differential and provenance policies.
- **Supersedes:** None
- **Superseded by:** None

## Context

Large rewrites of layout, shaping, rasterization, codecs, or platform protocols can appear complete while hiding signedness, overflow, lifetime, or edge-case divergence.

## Decision

A readable reference implementation, specification or pinned Oracle, fixed corpus, and fuzz target precede algorithmic rewrites, SIMD, parallelism, or GPU acceleration.

## Consequences

Ports retain upstream mapping, provenance, accepted-difference policy, reproducible fixtures, and independent adversarial review. Performance cannot select an implementation that fails correctness gates.

## Evidence

Each consuming milestone names its Oracle, corpus, tolerances, budgets, and upgrade procedure before optimized work is accepted.

## Replacement

None.
