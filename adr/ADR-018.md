# ADR-018: Make animation transaction-scoped, interruptible, and phase-aware

- **Status:** Accepted
- **Date:** 2026-08-14
- **Decision milestone:** ADR-BOOTSTRAP-001
- **Evidence:** PLANS.md Sections 4 (ADR-018), 7, 18, and 26; SwiftUI animation references in REFERENCES.lock; `modules/runtime` animation kernel and `m1-animation` conformance profile.
- **Supersedes:** None
- **Superseded by:** None

## Context

Curve-only animation APIs do not define committed values, interruption, velocity, atomic sampling, lifecycle transitions, reduced motion, or which pipeline phases must run.

## Decision

Committed state and mounted properties are authoritative model targets; active animation derives separate presentation values. Immutable animation metadata travels with the state/publication transaction. All due presentation values sample one monotonic timestamp and publish one presentation epoch without writing application state or executing effects. Each property declares typed interpolation and earliest phase impact.

## Consequences

Compatible replacements preserve current value and meaningful velocity; other policies explicitly restart, blend, or snap. Completion is an exactly-once bounded event delivered after sampling rather than an application callback invoked by the sampler. Bounded compositor animation contains no application callback and remains reproducible by the UI runtime. Structural and matched-geometry behavior use explicit identity and lifecycle contracts.

## Evidence

`ANIM-CORE-001` implements immutable requested/effective animation transactions, separate scalar model and presentation values, atomic manual-clock sampling, canonical phase impacts, allocation-free steady-state scalar sampling, reference cubic Bézier tweens, analytic springs, compatible velocity-preserving retargeting, disabled-motion substitution, bounded completion reservations, and exactly-once terminal events. Fifteen deterministic unit and concurrency cases cover commit failure atomicity, skipped frames, sampling-frequency independence, exact spring values and velocities, interruption policies, gesture velocity, reduced motion, lifecycle cancellation, cross-thread snapshot publication, and compositor-only phase isolation.

The active `m1-animation` profile executes these contracts against the Headless manual clock and writes `build/conformance/m1-animation/results.json`. This evidence closes the M1 scalar reference kernel only. Later `ANIM-001` and `TRANSITION-001` profiles still cover higher-order motion, transaction precedence in mounted UI commits, animated hit testing and semantics, compositor offload equivalence, structural transitions, matched geometry, tracing, replay, and performance budgets.

## Replacement

None. Surface API design may adapt SwiftUI ideas but cannot require its compiler/macro or per-frame closure model.
